## 👋 About Me

I'm a backend engineer with **9+ years of Java experience**, now focused on **AI Agent application engineering**.

I work at the boundary between mature software engineering and LLM-based systems — turning model capabilities into systems that can actually connect to **tools, data, permissions, workflows, and production environments**.

My current interests are not limited to building demos. I care more about how agents are **orchestrated, observed, constrained, evolved, and shipped**.

> From backend systems to agentic systems.

- **Tool Ecosystem** — Tool Calling, MCP, Skills, Agent Gateway, AI IDE integration
